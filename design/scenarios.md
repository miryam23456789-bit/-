# Scenarios

## 1. Find a Single Furniture Item Within Budget

The user enters a furniture type (e.g., "sofa") and a maximum budget, and sees one matching item from the catalog within that budget.

| User Input (Item & Budget) | Expected Output |
| --- | --- |
| Item: Sofa, Budget: 1000 NIS | Modern Sofa - 700 NIS |
| Item: Rug, Budget: 200 NIS | Modern Rug - 150 NIS |
| Item: Sofa, Budget: 300 NIS | No matching item found within budget |
