# HomeMind AI - מודולים ותחומי אחריות

## 1. Vision & Image Analysis Module (ראייה ממוחשבת)
- **אחריות:** קבלת תמונת חדר מהמשתמש, זיהוי סוג החלל (סלון), צבעים קיימים ורהיטים נוכחיים.

## 2. Conversation & Profiling Module (מודל שפה - LLM)
- **אחריות:** ניהול דיאלוג עם המשתמש, אפיון העדפות סגנון, צרכים ומגבלות תקציב.

## 3. Product Catalog & Search Module (חיפוש ו-RAG)
- **אחריות:** אינדוקס קטלוג רהיטים מצומצם, חיפוש סמנטי (Embeddings) של פריטים תואמים לפי סגנון ומחיר.

## 4. Recommendation & Plan Module (אופטימיזציה ותכנון)
- **אחריות:** הרכבת סל קניות מומלץ (רשימת פריטים), חישוב סך המחיר ואימות עמידה בתקציב.
